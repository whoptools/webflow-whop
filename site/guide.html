Set up Whop Checkout

  1. Create a product and checkout plan in Whop. Copy its plan ID or direct checkout URL.
  2. Open the app in Webflow. Choose Sandbox for a sandbox plan, or Production for a live plan.
  3. For a button, select a container and click Add checkout button.
  4. For an embed, connect Webflow, check the connection, and enable embedded checkout. This installs the app’s checkout script through Webflow’s Custom Code API. The script loads Whop Elements through its official loader.
  5. Add the checkout, then publish the site from Webflow. Open the published page to test it.

Editing

Select a checkout element and choose Load selected. Change its plan or settings and click Update selected. Use Webflow’s Style panel for layout and button styling. Add a new element when switching between button and embed.

Payments and fulfillment

Whop sets prices, collects payments, and manages its product access. This app does not create Webflow Ecommerce orders or restrict access to Webflow pages. Custom fulfillment belongs in a server-side integration that verifies Whop payment webhooks.

A return URL can receive succeeded, failed, canceled, or pending outcomes. It is not proof of payment. Apple Pay requires domain verification with Whop and a supported browser; sandbox wallets are not available.

Requirements

Embedded checkout requires Webflow access to custom code. Buttons are ordinary links. Published embeds load Whop’s payment SDK and this app’s versioned initialization script; only elements created by this app are initialized.

Remove the integration

In the app, open Remove integration and choose Remove scripts and disconnect. Publish the site to remove the scripts from the live page. Delete any Whop Checkout elements from the Designer, then uninstall the app in Workspace settings. If you uninstalled first, remove the app’s checkout script in site Custom Code settings and publish. Unrelated scripts are preserved.
