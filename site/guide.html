Whop Checkout for Webflow

Setup guide

Five steps from Whop plan to live checkout.

  1. Get a plan. In Whop, create a product and plan. Copy the plan ID or checkout URL.
  2. Open the app in the Webflow Designer. Pick Sandbox or Production to match the plan.
  3. Button: select a container, click Add checkout button.
  4. Embed: connect Webflow, click Check connection, enable embedded checkout. This installs a versioned script via Webflow’s Custom Code API.
  5. Publish the site and test the live page.

Edit

Select an element → Load selected → change it → Update selected. Style with Webflow’s Style panel. Switching button ↔ embed needs a new element.

Payments

  • Whop sets prices, takes payments and grants access. No Webflow Ecommerce orders, no page gating.
  • Return URLs report succeeded, failed, canceled or pending. Not proof of payment: verify Whop webhooks on your server.
  • Apple Pay needs Whop domain verification. No wallets in sandbox.

Requirements

Embeds need Webflow custom code access. Buttons are plain links. Only elements this app created are initialized.

Remove

App → Remove integration → Remove scripts and disconnect → publish. Delete the checkout elements, then uninstall in Workspace settings. Already uninstalled? Remove the script in site Custom Code settings and publish. Other scripts stay untouched.
