# webflow-whop agent instructions

## Shared WhopTools handbook

Before working in this repository, read the private [WhopTools handbook](https://github.com/whoptools/handbook), starting with its [WhopTools skill](https://github.com/whoptools/handbook/blob/main/skills/whoptools/SKILL.md) and the references relevant to the task. Use it for organization conventions, Frosted UI, automatic system themes, signup links, deployment, releases and PR approvals.

Read the contents through authorized GitHub access, an up-to-date local handbook clone or the installed `whoptools` skill; a link alone does not load the instructions. If the handbook is inaccessible, report that and request access or the relevant excerpt before work that depends on its conventions. Do not copy private handbook contents into this repository's public files, issues or PRs.

Use the handbook for current organization conventions and keep this repository's technical instructions alongside it. Follow newer explicit user decisions when older notes conflict. Never merge a PR, enable auto-merge or enqueue it without explicit user approval for that PR or an identified batch.
